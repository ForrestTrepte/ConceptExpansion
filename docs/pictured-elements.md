# Pictured elements

What is drawn inside each board icon, for checking prompts against guideline test 9
(**not pictured on the board**, see [prompt-guidelines.md](prompt-guidelines.md)).
Back to [README](../README.md).

Some groups place a cube right on one detail of an icon's picture. A prompt that is
one of these elements then goes in one step, so it's ruled out. Compounds built from
an element are fine (*Lighthouse* = the A8 light bulb + B14), but they are easier
than the words suggest, so band them with the pictured part counted as direct.

How to read the table:

- **Elements** are the things a player would name if a cube pointed at them. Names
  follow what most players would call the drawing, with the likely alternative in
  parentheses (e.g. "turtle (tortoise)").
- **Look-alikes** are drawings of a specific real thing, person, or brand that isn't
  named on the icon. They count as pictured if players would name them on sight.
- **Small details** are drawn clearly but small, or are parts of a larger drawing.
  They count as pictured: a cube can sit right on the windows of B14's house.
- **Background** patterns (graph paper, checkerboard, brick) are not counted.

Descriptions only; the artwork is Repos Production's. To see the pictures, run
`python tools/player_aid.py` and open `output/player-aid/pictured-elements.md`, a copy
of this page with each icon's picture beside its row.
